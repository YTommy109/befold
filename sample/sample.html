HTML サンプル

befold の HTML プレビュー機能を確認するためのサンプルファイル。 .html は <iframe> の srcdoc へ流し込んで 描画するため、ページ内の CSS がそのまま効く。

見出しと段落

この段落が本文として表示され、上の見出しに罫線が付いていれば、 ページ内 <style> が適用されている。

iframe の高さは読み込み後にコンテンツの scrollHeight へ追従する （取得できない場合は 80vh にフォールバックする）。

箇条書き

  • ページ内の CSS はそのまま適用される
  • iframe には sandbox="allow-same-origin" が付く
  • allow-scripts は付けないため、スクリプトは実行されない
