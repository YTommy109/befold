## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
feat/preview_mode の /code-review (high) の振り返りから。指摘 10 件中 4 件（TASK-368〜371）は「モード × ファイル種別 × 入口ごとの期待挙動」を列挙した仕様が無く、遷移・永続化・no-op の期待がコードの成り行きで決まっていたことに起因する。ADR 0002 は capability のガード責務は定めており実際にレビュー基準として機能したため、新規文書ではなく ADR 0002 への追記とする。

追記する内容:
- 遷移表: 各表示モード（rendered / source / diff）×入口（セグメント選択・cmd+1〜4・cmd+U トグル・CLI --source/--preview・復元・リネーム・ファイル切替）ごとの期待遷移
- 永続化規則: どの遷移が DisplayModeStore へ書くか（例: CLI 上書きは書かない、.code への .source は書かない）
- no-op 規則: 選択済みモードの再選択・サポート外ファイル種別での挙動
- 不変条件の置き場所: 「同一ファイルを開いた全ウィンドウは同じ表示モードを示す」（TASK-371。旧 DiffDisplayPreference の doc コメントにだけ書かれていてクラス削除と共に消えた）を ADR 側へ移す

TASK-368〜371 の修正はこの遷移表を基準に突き合わせるのが望ましい。
