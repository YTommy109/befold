## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
AboutWindowController / AIIntegrationWindowController / FeatureOverviewWindowController / KeyboardShortcutsWindowController / OSSLicensesWindowController / CodeFontSettingsWindowController（befold/App/）の 6 個がほぼ完全な同型コピー。isFrontmost・showAndActivate()・toggle() は 1 文字も違わず、convenience init の構成手順も同一。AppDelegate.swift:314-343 の「controller ?? Make(); store; toggle()」も 6 回繰り返されている。NSHostingController ベースの共通基底（HostedPanelWindowController）に統合し、AppDelegate 側も辞書 + 1 メソッドに畳む。約 200 行 → 60 行の見込み。CodeFontSettingsWindowControllerTests が isFrontmost 注入を前提にしているためシームは基底に残す。styleMask の resizable 有無・setContentSize の有無は挙動差なので明示引数にする。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. HostedPanelWindowController(共通基底)を新設し、showAndActivate/toggle/isFrontmost シームを集約
2. 差分(タイトル・中身のビュー・サイズ・リサイズ可否)は init 引数で受ける
3. 6 個の同型コントローラを削除し、AppDelegate は HostedPanel をキーにした辞書 + togglePanel/makePanelController に畳む
4. 生成側は AppDelegate+HostedPanels extension へ分離(型の肥大化を避ける)
5. テストを HostedPanelWindowControllerTests へ移し、styleMask/minSize の反映も固定
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
6 個の同型コントローラ(About / AIIntegration / FeatureOverview / KeyboardShortcuts / OSSLicenses / CodeFontSettings)を削除し、HostedPanelWindowController 1 つへ統合した。差分は init 引数(rootView / title / resizable / contentSize / minSize)にしてあり、styleMask の resizable 有無と setContentSize の有無という実挙動差は引数として明示されている。AppDelegate 側の『controller ?? Make(); store; toggle()』6 連コピーは HostedPanel をキーにした辞書 + togglePanel(_:) 1 メソッドへ集約し、パネルごとの差分は makePanelController の switch 1 箇所だけに残した。生成側は AppDelegate の型サイズ上限(SwiftLint type_body_length 350)を超えるため AppDelegate+HostedPanels.swift の extension へ分離し、あわせて windowManager / codeFontPreference の private を internal へ緩めた。行数は 6 ファイル計 約200 行 → 基底 50 行 + 生成 switch 60 行。isFrontmost シームは基底に残したためテストの注入方式は不変で、テストは CodeFontSettingsWindowControllerTests から HostedPanelWindowControllerTests へ移設（3 件そのまま + styleMask/minSize の反映を固定する 2 件を追加）。ファイル増減があるため xcodegen generate 済み(project.pbxproj は .gitignore 対象)。検証: swift test → 941 passed / swiftformat --lint パス。
<!-- SECTION:NOTES:END -->
