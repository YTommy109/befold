---

## Description

## ゴール

差分をソース表示に限定せず、Markdown のレンダリング表示や CSV/TSV のテーブル表示のまま
変更箇所を読めるようにする。読み手が普段見ている形を崩さずに差分を重ねることが目的。

## 含む

- CSV/TSV のソース行とレコードの対応付け、テーブル表示へのレコード単位の差分
- レンダリング Markdown における差分表現の設計と実装

## 含まない

- HTML / PDF / 画像など Markdown・CSV/TSV 以外の形式への差分表示
- 比較基準の選択。コミット履歴のマイルストーンで扱う

## 完了条件

- CSV/TSV のテーブル表示でレコード単位の差分が読める
- Markdown のレンダリング表示で差分が読める
- ソース表示に切り替えなくても変更箇所を把握できる
