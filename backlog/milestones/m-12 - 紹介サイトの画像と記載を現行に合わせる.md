## Description

## ゴール

配布サイトのスクリーンショットと機能記載を、現行の UI・実装に合わせる。旧 m-1（紹介サイトを現在の機能に追随させる）の続き。

## 含む

- スクリーンショットの撮り直しと、スライド窓・比較基準の切り替え・PDF 内検索の画像追加（TASK-690）
- 上記 3 機能の説明の追加（TASK-691）
- 言語数表記・ショートカット表・CLI フラグ・古いコメントの食い違いの修正（TASK-692）
- 未検証の記載の実測と、ずれを検知する仕組み（TASK-693）
- 課題起点のページと QuickLook の訴求（TASK-519 / 520。520 が依存する TASK-518 は m-10 に属する）

## 含まない

- サイトの技術基盤（Worker・ドメイン・認証）の変更
- アプリ本体の機能追加

## 完了条件

- サイト上のスクリーンショットが現行 UI で撮影され、撮り直す対象と据え置く対象が理由つきで記録されている
- スライド窓・比較基準の切り替え・PDF 内検索がサイトに載っている
- サイトの記載のうち未検証だった主張が実測で裏取りされている
- サイト記載の機能・ショートカットが現行実装と一致している

## 調査記録（2026-10-09）

コード読みによる突き合わせ。site の vitest は止まって未実行。ショートカット・対応形式・サイズ上限・CLI フラグは確認できた範囲で実装と一致。食い違いは「50以上の言語」（拡張子 50・言語 30）のみ。スクリーンショットは 1〜6 が 07-29/30 撮影で、3 と 8 は旧 UI を目視で確認済み。
