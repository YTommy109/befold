## Description

## ゴール

差分を「何と比べるか」をユーザーが選べるようにし、stacked PR を含むブランチ作業の変更を、見たい範囲だけで読めるようにする。

m-3「コミット履歴から変更を追えるようにする」を置き換える。m-3 は「比較基準の切り替え設定を新設せず、コミット一覧の先頭エントリで両方の見方を出す」としていたが、stacked PR では既定の基準（デフォルトブランチとの merge-base）がスタックの根元になり、一つ前の PR までの変更が混ざることが分かったため、基準の切り替えを先に出す形へ組み替えた（TASK-353 の Notes、2026-10-08）。

## 段階

1. 比較基準の切り替え（TASK-353）: このブランチの変更（親ブランチ基準）／スタック全体の変更／作業中の変更の 3 つを窓ごとに選ぶ
2. コミット一覧: 現在のブランチのコミットを一覧し、選んだコミットの差分を読む。一覧の先頭には段階 1 の 3 基準をそのまま置く

## 含まない

- ブランチの切り替え・チェックアウトなど、履歴を書き換える／作業ツリーを変える操作
- コミットの作成・取り消し・ステージ操作
- 任意の 2 コミット間やブランチ間の比較

## 完了条件

- stacked PR のブランチで、既定で一つ前のブランチからの変更だけを読める
- 差分モードでは、何との差分かが常に画面に出ている
- サイドバーのバッジと差分ビューアの基準が食い違わない
- コミット一覧から差分へ到達できる
