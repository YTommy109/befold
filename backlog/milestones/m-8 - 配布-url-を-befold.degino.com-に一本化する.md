## Description

## ゴール

配布・更新の経路を befold.degino.com だけに畳む。現在は GitHub Pages
（ytommy109.github.io）・workers.dev・独自ドメインの 3 世代がすべて現役で、
旧世代は「消せない」のではなく「消せる条件が観測できていない」状態にある。
観測できる形にしたうえで、条件を満たしたものから順に止める。

## 含む

- 停止条件の明文化（ADR 0007 の更新）
- 旧ホスト・旧経路へのアクセスの観測
- 条件に関係なく消せる残骸の削除
- 条件充足後の GitHub バイナリ配布停止と旧ホスト停止

## 含まない

- ソースリポジトリとしての github.com/YTommy109/befold へのリンク。
  これは残す（Issues・作者プロフィール・リポジトリ本体）
- R2 を正とする配布構造そのものの変更

## 完了条件

- 旧世代 URL を停止できる条件が観測可能な形で ADR に書かれている
- 旧ホストと GitHub 直経路へのアクセス数が数字で分かる
- 条件を満たさないうちは止めないことが、担保付きで守られている
