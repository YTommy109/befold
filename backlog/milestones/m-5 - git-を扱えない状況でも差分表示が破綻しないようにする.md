title: "git を扱えない状況でも差分表示が破綻しないようにする"
---

## Description

## ゴール

差分表示まわりの「壊れて見える」振る舞いを取り除く。git を扱えないリポジトリ・
フォルダーで誤った表示や選べないはずの選択肢を出さないこと、および表示切り替え時の
描画のちらつきをなくすことが目的。

## 含む

- git を扱えないリポジトリであることの利用者への伝え方の確定
- BaseDirectoryIndicator の誤表示（「Plain folder」）の解消
- 差分表示モードの選択可否を git の状態から導出する
- 差分表示へ切り替える際に一瞬プレーンなソース表示が出る問題の解消
- 関連 ADR の Fallback 節の確定と ADR 番号の衝突解消

## 含まない

- 差分の見せ方の拡張（レンダリング表示への重ね合わせ）
- 比較基準の選択・コミット履歴

## 完了条件

- git を扱えないリポジトリで、選べない理由が利用者に伝わる（誤った表示をしない）
- 選択可否が git の状態から導出されており、状態と UI が食い違わない
- 差分表示への切り替えでプレーンなソース表示が一瞬でも見えない
