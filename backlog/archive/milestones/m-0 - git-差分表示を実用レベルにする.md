## Description

## ゴール

差分が「ソース表示でしか見られない／比較基準が固定／git を扱えないリポジトリでの挙動が不明」という現状を脱し、
レンダリング表示のまま、比較基準を選んで変更箇所を読める状態にする。

## 含む

- 比較基準の切り替え（未コミットの変更 / ブランチの変更）
- レンダリング表示（Markdown・CSV/TSV）への差分の重ね合わせ
- git を扱えないリポジトリ・ディレクトリでの表示と選択可否の確定
- 差分表示へ切り替える際の描画のちらつき解消

## 含まない

- コミット履歴の閲覧・ブランチ操作など、ビューア以外の git 機能
- HTML / PDF / 画像など Markdown・CSV 以外のレンダリング形式への差分表示

## 完了条件

- 差分表示がソース表示に限定されず、Markdown と CSV/TSV のレンダリング表示で使える
- 比較基準を UI から切り替えられる
- git を扱えないリポジトリで、選択できない理由が利用者に伝わる（誤った表示をしない）
