## Description

## ゴール

独自ドメイン befold.degino.com へ移行した配布サイトの内容を、現行の機能と
ふたつの読み手（Markdown を書く人 / 受け取って読む人）に合った形に更新する。

## 含む

- ショートカット表・機能記載の陳腐化解消
- git 機能の紹介追加（説明とスクリーンショット）
- 読む立場の人にとっての利点の整理と LP 訴求セクションの書き直し

## 含まない

- サイトの技術基盤（Worker・ドメイン・認証）の変更。TASK-476 で完了済み
- アプリ本体の機能追加

## 完了条件

- サイト記載の機能・ショートカットが現行実装と一致している
- git 機能がサイト上で説明され、スクリーンショットで確認できる
- LP の訴求がふたつの読み手に向けて書かれている
