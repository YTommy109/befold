## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
開いたファイルが git リポジトリ内だった場合、そのリポジトリ（本体または worktree）のルートを自動的に「最近使ったリポジトリ」として記憶し、メニューから素早く再オープンできるようにする。

## 開く挙動（確定）
メニュー項目を選ぶと、そのリポジトリ/worktree の**ルートディレクトリを新規ウィンドウのサイドバーで開く**（既存の「フォルダを開く」経路に乗せる）。前回のタブ構成復元（SessionRestorer 連携）は本タスクのスコープ外とし、将来拡張とする。

## 記憶する単位
開いたファイルから解決した git リポジトリのルート（worktree の場合は worktree のルート）。重複排除キーはルートパス。最終利用順で並べ、保持件数上限を設ける。永続化は UserDefaults。

## 本体 vs worktree の区別
git rev-parse の --git-common-dir と --git-dir の比較（一致＝本体、不一致＝worktree）等で判定し、一覧上で本体か worktree かを区別できるラベル/表示にする（例: リポジトリ名に worktree 名やブランチを併記）。

## オープンな論点（着手時に研究して決める）
- 保持件数の上限値、一覧のクリア手段の有無
- 既存の「最近使ったファイル」系メニューとの並置/統合
- worktree ラベルの具体表記（ブランチ名 / ディレクトリ名）
