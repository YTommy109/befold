## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
プレビューの表示モードは現在ファイルを開くたびにそのファイルの記憶（`SourceModeStore.swift:11`、キー `ViewerSourceModes`）に従って決まる。TASK-356 でこの粒度を差分にも揃え、モードは一貫してファイル単位の記憶になる。

その上で、「どのファイルを開いても常に同じモードで表示したい」というユーザーの要望を満たす設定を追加する。ファイルごとの記憶に従うか、アプリ全体で固定したモードを使うかを選べるようにする。

## 背景

ファイル単位の記憶は「前回このファイルをソースで見ていたから今回もソース」という追随が効く反面、「自分は常にソースで見たい」という使い方には毎回の切替が要る。両方の使い方を成立させるため、記憶の追随そのものを設定で無効化できるようにする。

## 設計上の論点（着手時に詰めること）

- 固定モードを指定する UI をどこに置くか（設定画面 / View メニュー / ツールバーのコンテキストメニュー）
- 固定が有効なとき、ツールバーでモードを切り替えたらどうなるか。(a) その場限りの一時的な変更で、次のファイルでは固定モードに戻る (b) 固定モードそのものを書き換える
- 固定の対象にレンダリング/ソース/差分のどこまでを含めるか。差分は `FeatureGate.isSourceDiffEnabled` 配下（`FeatureGate.swift:61`）のため、stable では固定候補から差分が消える点の扱い
- ファイル種別によって選べないモードがある（`FileType.swift:167-172` `supportsDiffDisplay` により CSV/TSV・画像・PDF は差分不可）。固定モードが適用できないファイルを開いたときのフォールバック

## 前提

- TASK-356 完了後に着手する。モードの粒度がファイル単位に揃っていることが前提であり、それ以前に着手すると差分だけアプリ全体という現在の食い違い（`DiffDisplayPreference.swift:4-12`）の上に設定を重ねることになる
- 状態と分岐を増やす変更のため、実装着手前に `/review-design` を 1 回回すこと
