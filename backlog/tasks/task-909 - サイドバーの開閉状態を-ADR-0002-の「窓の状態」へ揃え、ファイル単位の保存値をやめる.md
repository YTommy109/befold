## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
サイドバーの開閉は文書に紐づかず、ADR 0002 の分類では「窓の状態」にあたる。しかし `SidebarStateStore.initialCollapsed` は 2026-07-19 の実装のまま「そのファイルの保存値 → 直近アクティブなファイルの保存値 → 最後の操作」の順で解決する（ADR に「窓の状態」が足されたのは 2026-08-14 で、例示は表示設定 4 値のみ）。さらに窓を開くだけで解決結果が `setCollapsed` でファイルへ書かれる。その結果、以前に閉じた状態で開いたファイルは、別の窓でサイドバーを開いた後でも、再起動や開き直しで閉じたまま始まる（コードからの判断で未再現）。意図する動作は、開いている間はウィンドウ単位、再起動時は最後のユーザー操作の保持。PR #750 が同じ `openViewer` に手を入れているため、取り込み後に行う。
<!-- SECTION:DESCRIPTION:END -->
