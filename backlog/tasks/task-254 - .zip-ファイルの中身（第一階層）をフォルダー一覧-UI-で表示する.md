## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`.zip` を befold で開いたときに、アーカイブの中身を一覧表示できるようにする。

## 背景・目的
現状 `.zip` はプレビュー対象外。中身をざっと確認するためだけに解凍するのは手間なので、
ビューア上で「何が入っているか」を確認できるようにしたい。

## スコープ
- 表示は**アーカイブの第一階層のみ**。ネストしたディレクトリの中身は展開しない
  （第一階層に現れるディレクトリはエントリとして表示するが、掘り下げは対象外）。
- 表示 UI は**既存のフォルダー一覧表示（TASK-61 で実装したフォルダープレビュー）をできる限り流用**し、
  zip 専用のビューを新設しない。列やソートの挙動も既存に揃える。
- パスワード付き zip は、一覧表示の前に**パスワード入力ステップ**を挟む。
- 入力されたパスワードは**永続化しない**（Keychain・UserDefaults 等に保存しない）。
  メモリ上にのみ保持し、同じアーカイブを再度開く際の再入力を避ける。
- ファイルの**展開・取り出しはスコープ外**（一覧表示のみ）。

## 検討が必要な点（実装時に判断し、必要ならユーザーに確認する）
- パスワード保持のライフタイム: 「アプリ起動中」か「そのウィンドウを閉じるまで」か。
  ユーザーの希望は「起動中〜ウィンドウを閉じるまでは再入力不要」で、より安全な
  ウィンドウ単位を既定とするか要検討。
- 暗号化方式による差異: 従来の ZipCrypto と AES では、エントリ名だけは暗号化されず
  読めるケースがある。その場合にパスワードなしで一覧を出すか、常に入力を求めるかを決める。
- zip 読み取りの実装手段（Foundation/Compression、`libarchive`、外部依存の追加可否）。
- 巨大アーカイブ・破損アーカイブ・パスワード誤入力時のエラー表示。
