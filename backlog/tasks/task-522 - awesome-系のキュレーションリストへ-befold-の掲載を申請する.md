## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
awesome-claude-code / awesome-mcp などのキュレーションリストは、それ自体が発見経路として機能する。befold（およびその Claude Code スキル）を掲載申請する。

現状: どのリストが実在し、掲載基準が何かをユーザーが調査中。調査結果が出るまでは着手できない。

着手可能になる条件: 申請先のリストが 1 つ以上特定され、その掲載基準（スター数・カテゴリ・PR の作法）が分かること。

前提: 掲載申請は多くの場合リポジトリへの PR で行うため、README や配布サイトが第三者の目に耐える状態であることが前提になる。申請前に一度その観点で見直す。
