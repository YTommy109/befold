## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ViewerWindowManager.controllers は [String: [ViewerWindowController]]（ViewerWindowManager.swift:15）で、同一ファイルを複数ウィンドウで開くことを意図的に許している（サイドバーの「新規ウィンドウで開く」は :231 の重複抑止をバイパスする）。

しかし viewerWindowWillClose（ViewerWindowManager.swift:465）は detach 後に sessionStore.noteClosed(controller.fileURL) を無条件で呼ぶ。SessionStore.noteClosed の実体は openFilePaths.remove(url)（SessionStore.swift:62）で参照カウントを持たないため、同じファイルを表示している窓が他に残っていてもセッション集合から消える。一致していれば保存中のアクティブパスも消す。

再現: notes.md を開き、サイドバーから「新規ウィンドウで開く」でもう 1 枚開く → 片方を閉じる → アプリを終了する。終了時は freeze() が走るので誰も再登録しない。次回起動の restoreLastSession() は notes.md を開き直さない。

remapController（:447）も同型で、窓 B が別ファイルへ切り替わると窓 A がまだ必要としているセッション項目を消す。
<!-- SECTION:DESCRIPTION:END -->
