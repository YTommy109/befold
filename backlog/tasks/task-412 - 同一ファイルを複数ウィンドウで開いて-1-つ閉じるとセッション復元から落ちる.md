## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ViewerWindowManager.controllers は [String: [ViewerWindowController]]（ViewerWindowManager.swift:15）で、同一ファイルを複数ウィンドウで開くことを意図的に許している（サイドバーの「新規ウィンドウで開く」は :231 の重複抑止をバイパスする）。

しかし viewerWindowWillClose（ViewerWindowManager.swift:465）は detach 後に sessionStore.noteClosed(controller.fileURL) を無条件で呼ぶ。SessionStore.noteClosed の実体は openFilePaths.remove(url)（SessionStore.swift:62）で参照カウントを持たないため、同じファイルを表示している窓が他に残っていてもセッション集合から消える。一致していれば保存中のアクティブパスも消す。

再現: notes.md を開き、サイドバーから「新規ウィンドウで開く」でもう 1 枚開く → 片方を閉じる → アプリを終了する。終了時は freeze() が走るので誰も再登録しない。次回起動の restoreLastSession() は notes.md を開き直さない。

remapController（:447）も同型で、窓 B が別ファイルへ切り替わると窓 A がまだ必要としているセッション項目を消す。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 単純化検討: SessionStore に参照カウントを新設せず、既存の ViewerWindowManager.controllers（正規化パス → コントローラ群）を唯一の真実とする。detach 後にそのキーが辞書から消えていれば「最後の 1 枚」と判定できるため、新しい状態は増やさない。
2. ViewerWindowManager に private helper noteClosedIfLastWindow(for:) を追加し、controllers[key] == nil のときだけ sessionStore.noteClosed を呼ぶ。
3. viewerWindowWillClose と remapController の無条件 noteClosed を両方この helper 経由へ一本化する（2 箇所が別判定にならない形にする）。
4. ViewerWindowManagerTests に 3 ケース追加: (a) 同一ファイル 2 窓 → 1 枚閉じてもセッション集合・アクティブ記録が残る, (b) 最後の 1 枚を閉じると消える, (c) 2 窓のうち片方が switchFile で別ファイルへ移っても元パスが残る。
5. swift test / swiftformat / swiftlint ベースライン差分ゼロを確認する。

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
単純化検討の結果: SessionStore に参照カウントを新設せず、既存の ViewerWindowManager.controllers（[正規化パス: [コントローラ]]）を参照の唯一の真実として使った。detach 後に controllers[key] == nil なら「最後の 1 枚」と判定でき、新しい状態も新しい経路も増えない。

実装: private func noteClosedIfNoWindowRemains(for:) を 1 つ置き、viewerWindowWillClose と remapController の無条件 noteClosed を両方そこへ通した（2 経路が別判定を持つ形を無くした）。

テスト: 新規 ViewerWindowManagerSessionRecordTests に 3 ケース。本体の ViewerWindowManagerTests へ足すと type_body_length（250 行）を新規に超えたため、規約どおり閾値を緩めず別ファイルへ分けた（xcodegen generate 実行済み）。

実測（修正前に 3 ケースを先に書いて失敗を確認）:
- 「1 枚閉じてもセッション記録は消えない」→ savedURLs が [] に、savedActivePath が nil になって失敗
- 「片方のファイル切替でも旧パスは消えない」→ savedPaths が ["/mock/second.mmd"] のみで失敗
- 「最後の 1 枚を閉じたら消える」は修正前から通過（従来挙動の固定）
修正後は swift test（Integration 込み）で 1374 tests / 200 suites すべて通過。

swiftlint ベースライン: HEAD 版を取り出して同一 config で比較。ViewerWindowManager.swift の 3 件（file_length / function_body_length / type_body_length）は変更前から存在し、ルール集合は不変。新規テストファイル・ViewerWindowManagerTests.swift は 0 件。swiftformat は fix モードで 0 files formatted。
