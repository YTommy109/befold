# だけを見る。ここに列挙したグループはその代わりに個別の上限で判定する。
#
# 形式: <グループキー><TAB><上限行数><TAB><理由>
#
# 理由は必須。空のエントリはスクリプトが弾く（「なぜ 400 に収まらないか」を書かないと
# 登録できない形にすることで、例外の追加を差分レビューで必ず目に付くようにする）。
# 例外は現状値の凍結（ラチェット）ではない。上限を超えない限り増減は自由で、逆に
# 上限まで太らせてよいという意味でもない。返済して閾値以下へ戻せたらこの行を消す。
